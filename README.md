# GTA VI Economy Map

A data analytics project predicting GTA VI launch pricing using historical 
Rockstar Games pricing data, US CPI inflation data, and Take-Two Interactive 
financials.

## Status
In Progress

## Tech Stack
- Python 3.11
- MySQL 8.0.39
- pandas, scikit-learn, streamlit

## Setup
```bash
conda env create -f environment.yml
conda activate gtavi-economy-map
```
